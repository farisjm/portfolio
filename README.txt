MOHAMED FARIS - Portfolio
=========================
Structure:
  index.html
  css/style.css
  js/script.js

Add these two files in the SAME folder as index.html:
  faris.jpg     -> your profile photo (shows "FM" fallback if missing)
  fariscv.pdf   -> your CV (used by View CV / Download CV buttons)

Open index.html in a browser, or deploy the folder to Netlify.
